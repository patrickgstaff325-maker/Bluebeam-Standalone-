# WRE Revu Assistant

Standalone Windows companion for Bluebeam Revu, focused on engineering drawing review, QA/QC, markups, takeoffs, and future AI-assisted workflows.

## B01 Foundation

- Tauri 2 desktop shell
- React + TypeScript frontend
- Rust backend
- Local-first architecture
- Revu-inspired workspace
- Shared-core boundaries for future WRE Engineering Suite integration

## Planned modules

Drawing Set Manager, QA/QC Inspector, Markup Assistant, Takeoff Assistant, AI Document Review, and Bluebeam Bridge.

## Development

Prerequisites: Node.js LTS, Rust stable, and Tauri 2 Windows prerequisites.

```bash
npm install
npm run tauri dev
```
