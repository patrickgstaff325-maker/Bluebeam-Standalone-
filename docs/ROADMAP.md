# Development Roadmap

## B01 — Foundation
Desktop shell, shared architecture boundaries, settings/project model, CI.

## B02 — PDF & Sheet Database
PDF import, page metadata, sheet identification, labels, bookmarks, set indexing.

## B03 — Drawing Set QA/QC
Sheet sequence, title block, revision, size/orientation, cross-reference and coordination checks.

## B04 — Markup Workflows
Engineering markup presets, issue metadata, review logs and standardized comments.

## B05 — Takeoffs
Pipe/fitting/valve/appurtenance counts, length/area measurements, structured export.

## B06 — AI Review
Document Q&A, review findings, summaries, punch lists and engineering-oriented assistance.

## B07 — Bluebeam Bridge
Supported Revu/Studio interoperability and handoff workflows.

## B08 — WRE Suite Integration
Extract shared packages and expose this tool inside the broader WRE Engineering Suite.
